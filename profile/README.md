# Performance

The application performs modifications quickly while consuming minimal system resources. Since it only updates supported Windows shell configuration, no unnecessary background processes or services remain active after configuration.

Users can always restore Windows to its default context menu configuration if desired.

---

# Troubleshooting

If changes do not appear immediately, restart Windows Explorer or sign out and back into Windows. Running the application with administrative privileges is recommended when modifying protected system menu entries.

Ensure no other shell customization utilities are modifying the same Explorer components simultaneously.
